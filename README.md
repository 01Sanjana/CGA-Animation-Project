
# A Small Act of Kindness 🎬

## About the Project
A short 2D animated story created for the Computer Graphics and Animation (CGA) practical using Python and Pygame.

## Story
A boy walking through a park notices a thirsty little bird. He offers it water, and the bird happily flies away.

## Technologies Used
- Python
- Pygame
- NumPy
- ImageIO

## Output
The animation is exported as an MP4 video.

## How to Run
1. Install Python.
2. Install the required libraries:
   pip install pygame imageio imageio-ffmpeg numpy
3. Run:
   python kindness_story.py

## Moral
Even a small act of kindness can make a big difference.
